Cómo funciona

  1. Amazon S3 publica esta página y envía tu URL a la API.
  2. Amazon EC2 ejecuta la API en FastAPI, que genera un identificador único.
  3. Amazon DynamoDB guarda el enlace. Al abrirlo, la API te redirige al destino.
